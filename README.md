# To Do List Application

A simple command line to do list program written in Python that helps you add, view, complete and delete daily tasks.

## Features

- Add new tasks to the list
- View all tasks with their completion status
- Mark a task as done
- Delete a task from the list
- Input validation for invalid menu choices and invalid task numbers
- Clear numbered menu that loops until you choose to exit

## Installation

1. Make sure Python 3 is installed on your system. You can check with:

```
python --version
```

2. Download or clone this project to your computer:

```
git clone <your-repository-url>
```

3. Open a terminal in the project folder.

4. Run the program:

```
python todo.py
```

5. Follow the on screen menu and enter a number from 1 to 5 to choose an option.
